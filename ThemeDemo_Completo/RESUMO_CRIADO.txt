🔄 O QUE VOCÊ PRECISA FAZER:
═══════════════════════════════════════════════════════════════════════════════

PASSO 1️⃣  - MODIFICAR Common.UI/Themes/Brushes.xaml
───────────────────────────────────────────────────────────────────────────────

  ADICIONE ESTAS 2 LINHAS antes de </ResourceDictionary>:

  <!-- Dynamic Window Brushes for Theme Support -->
  <SolidColorBrush x:Key="WindowBackgroundBrush" Color="{DynamicResource WindowBackgroundColor}"/>
  <SolidColorBrush x:Key="WindowForegroundBrush" Color="{DynamicResource WindowForegroundColor}"/>


PASSO 2️⃣  - CONVERTER StaticResource → DynamicResource
───────────────────────────────────────────────────────────────────────────────

  EM TODOS OS ARQUIVOS DE TEMA (Buttons.xaml, Labels.xaml, Windows.xaml, etc):

  ANTES:  {StaticResource CorBlack}
  DEPOIS: {DynamicResource CorBlack}

  Use Find & Replace:
    Find:    StaticResource
    Replace: DynamicResource
    (Apenas nos arquivos de Themes/)


PASSO 3️⃣  - USAR O ThemeManager NO SEU PROJETO
───────────────────────────────────────────────────────────────────────────────

  Copie: ThemeDemo/ThemeManager.cs → Seu projeto

  Use assim:
    ThemeManager.SetTheme(ThemeMode.Dark);
    ThemeManager.SetTheme(ThemeMode.Light);
    ThemeManager.SetTheme(ThemeMode.System);


PASSO 4️⃣  - IMPLEMENTAR NO App.xaml.cs
───────────────────────────────────────────────────────────────────────────────

  protected override void OnStartup(StartupEventArgs e)
  {
      base.OnStartup(e);
      var savedTheme = Properties["Theme"]?.ToString() ?? "System";
      if (Enum.TryParse<ThemeMode>(savedTheme, out var theme))
      {
          ThemeManager.SetTheme(theme);
      }
  }


PASSO 5️⃣  - ADICIONAR DROPDOWN NA INTERFACE
───────────────────────────────────────────────────────────────────────────────

  <ComboBox x:Name="ThemeCombo" SelectionChanged="ThemeCombo_SelectionChanged">
      <ComboBoxItem Content="Light"/>
      <ComboBoxItem Content="Dark"/>
      <ComboBoxItem Content="System" IsSelected="True"/>
  </ComboBox>

  E no code-behind:
  private void ThemeCombo_SelectionChanged(object sender, SelectionChangedEventArgs e)
  {
      if (ThemeCombo.SelectedItem is ComboBoxItem item &&
          Enum.TryParse<ThemeMode>(item.Content?.ToString(), out var theme))
      {
          ThemeManager.SetTheme(theme);
          Application.Current.Properties["Theme"] = theme.ToString();
          Application.Current.SaveProperties();
      }
  }

❓ DÚVIDAS?
═══════════════════════════════════════════════════════════════════════════════

  Q: Por que usar DynamicResource e não StaticResource?
  A: StaticResource é resolvido em tempo de compilação.
     DynamicResource é resolvido em runtime, permitindo mudanças.

  Q: O System Theme funciona em Windows 7?
  A: Não. Funciona apenas Windows 10+. Vai para Light automaticamente.

  Q: Como adicionar novos temas?
  A: Crie novo arquivo em Common.UI/Themes/MeuTema.xaml
     e adicione a enum em ThemeMode do ThemeManager.

  Q: Como customizar as cores?
  A: Edite LightTheme.xaml e DarkTheme.xaml
     Altere os valores de Color="#..."
